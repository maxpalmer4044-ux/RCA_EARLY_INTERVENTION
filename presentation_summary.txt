The original version was hard to defend because it mixed failure-state information with upstream analysis and could overstate what the model knew. The updated pipeline fixes that by using the clean point-level dataset, splitting by run (`COIL + DATE`), and keeping the pre-defect models upstream-only so they do not leak active defect rows into the warning task.

The in-defect models now act as the baseline reference: they are easier because they see the defect region itself (`any_defect` forest PR-AUC 0.805). The early-warning models are intentionally harder because positives are rare by design. Within that harder setting, 50m is the best presentation window because it has the stronger sparse-label ranking metric (`pre_any_defect_50m` forest PR-AUC 0.031 vs 0.010 at 200m) and stays closest to the point where operations can still intervene.

At the system level, the main story stayed the same: Combustion, Cooling, Thermal dominate the general 50m warning signal. The added type 3 in-defect target improves completeness, but it does not change the main conclusion: baseline detection is easy, true early warning is harder, and the 50m upstream window is the clearest operational view.
